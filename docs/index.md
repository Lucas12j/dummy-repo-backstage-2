# Example Orders Service

Servico demonstrativo de pedidos criado para importacao no Backstage.

## Responsabilidades

- Criar e consultar pedidos.
- Expor uma API OpenAPI.
- Consumir uma API de pagamentos.
- Persistir dados no PostgreSQL.
- Utilizar Redis para cache e processamento assincrono.

## Execucao local

```bash
npm install
npm start
```

Acesse `http://localhost:8081/health`.
